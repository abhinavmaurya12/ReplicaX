# 🚀 ReplicaX

### One Platform. Multiple Website Replicas.

ReplicaX is a web development project dedicated to recreating and exploring popular website designs through frontend development. It serves as a growing collection of website replicas built to practice UI/UX design, responsive layouts, and modern web development techniques.

🔗 **Live Demo:** [ReplicaX](https://abhinavmaurya12.github.io/ReplicaX/)

---

## ✨ About the Project

ReplicaX is a hands-on project created to improve frontend development skills by building website replicas inspired by existing websites.

The goal is to understand how real-world websites are structured, how their interfaces work, and how to recreate similar experiences using web technologies.

## 🎯 Features

- 🌐 Website replica showcase
- 🎨 Modern and clean user interface
- 📱 Responsive design for different screen sizes
- 💻 Frontend development practice
- 🧩 Modular structure for adding more replicas
- 🚀 Hosted using GitHub Pages

## 🛠️ Technologies Used

- **HTML5** — Web page structure
- **CSS3** — Styling and layouts
- **JavaScript** — Interactive functionality
- **Git & GitHub** — Version control and source code hosting
- **GitHub Pages** — Website deployment

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/abhinavmaurya12/ReplicaX.git
```

### 2. Navigate to the Project

```bash
cd ReplicaX
```

### 3. Run the Website

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for local development.
